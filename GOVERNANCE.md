# Governance

generic-ml-executor is maintained by Daniel Slobozian, who decides on scope, design and releases.

- Changes reach `main` only through pull requests. A pull request is merged when the required checks `ci` and `no AI attribution` pass.
- Releases are published only by the release pipeline (`.github/workflows/release.yml`), never from a developer machine.
- Questions and proposals are welcome as GitHub issues.
